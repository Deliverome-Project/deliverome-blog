| **Text, figures, and protocols**: READMEs, `protocol/`, rendered `figures/*.png` and `*.pdf` | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribute as *Authors (Year). Post title. Deliverome blog. URL.* |
| **Third-party data** | Keeps its original license, which each post records in `data/README.md`. We commit it only where its terms allow redistribution. |
| **Manrope font** (`assets/fonts/`) | SIL Open Font License 1.1; see `assets/fonts/OFL.txt`. |

A post's README can override this for that post's material, and must say so explicitly.
